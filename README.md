# 你的boss助手

BOSS直聘 网页版自动化招聘助手 · **单文件版**：**精准筛选候选人 → 按计划批量打招呼**，带图形界面，全程在你自己电脑上运行。

用 Python + [DrissionPage](https://github.com/g1879/DrissionPage) 驱动本机已安装的 Chrome / Edge 浏览器操作网页版。**没有服务端、不上传任何数据**：岗位配置和候选人记录都只存在本机。

> 仅适用于持有 BOSS直聘 招聘者账号的企业招聘场景。使用前请阅读文末[免责声明](#免责声明)。

---

## 关于「单文件版」

本仓库是**单文件版**：全部逻辑集中在 `boss_recruiter.py` 一个文件里（约 3000 行），复制走一个文件就能跑，适合快速上手和二次修改。

另有一个**模块化开发版**，把界面、AI 自动回复、知识库、频率控制拆成多个模块，功能更多：

👉 [zhbo192883/HRBOSS](https://github.com/zhbo192883/HRBOSS)

两个版本是两套独立代码，按需选用即可。

## 功能特性

| 模块 | 说明 |
| --- | --- |
| **精准筛选** | 学历、年龄、性别、活跃度、薪资区间、跳槽频率、简历关键词（包含任一/必须全部/关闭）、目标公司词、屏蔽公司词、排除词 |
| **批量打招呼** | 每日沟通上限、单轮扫描上限、定时开始/结束、最短与最长随机间隔，可设为「机器自适应」自动在自然区间内等待 |
| **沟通话术** | 支持多条话术模板（一行一条），运行时随机选用，避免所有人收到同一句；`{职位}` 会自动替换为当前岗位 |
| **作息模拟** | 连续运行指定分钟后自动暂停一次，暂停时模拟点击左侧其他模块再回到「推荐牛人」，降低长期连续操作的特征 |
| **去重记忆** | 打过的候选人写入 `contacted_fingerprints.json`，不再重复打扰同一人 |
| **实时播报** | 命中候选人在界面滚动显示，右侧实时日志按等级着色 |
| **结果导出** | 自动生成 `matched_candidates.csv`、`skipped_candidates.csv`、`run.log`、`journal.jsonl` 和异常截图 |

## 环境要求

- **Windows 10 / 11** —— 代码使用 `winreg` 查注册表定位浏览器，暂不支持 macOS / Linux
- **Python 3.9+**，需自带 `tkinter`（Windows 官方安装包默认包含）
- 本机已安装 **Chrome 或 Edge**（优先用 Chrome，找不到才用 Edge）
- 一个 **BOSS直聘 招聘者账号**

## 快速开始

**1. 获取代码**

```bash
git clone https://github.com/zhbo192883/boss-assistant.git
cd boss-assistant
```

**2. 安装依赖**

```bash
pip install -r requirements.txt
```

**3. 启动程序**

```bash
python boss_recruiter.py
```

**4. 连接浏览器并登录**

点击界面上的 **「① 启动浏览器」**。程序会用调试端口 `9333` 拉起浏览器，窗口自动占据屏幕左半边，并打开「推荐牛人」页面。

在弹出的窗口里**扫码登录 BOSS直聘 招聘者账号**，登录完成后点 **「② 开始招聘」**。

> 程序使用的是**独立浏览器配置目录**（`browser_runtime/user_data`），和你日常用的 Chrome 完全隔离 —— 书签、插件、已登录的账号都不会带过来，所以**第一次必须扫码登录一次**。登录态之后会一直保存在这个目录里，下次启动无需重复登录。

**5. 配置筛选条件并开始**

在左侧「精准筛选」区填写岗位、学历、年龄等条件，在「执行计划」区设定节奏，然后点「② 开始招聘」。

## 界面说明

界面分左右两栏。

**左栏**

- **精准筛选** —— 岗位、简历关键词、活跃度、公司词、年龄、学历、性别、薪资、跳槽频率。每项右侧有 `?` 图标，**鼠标悬停可看到该字段的完整判定逻辑**，建议先看一遍。
- **执行计划** —— 定时开始/结束、最短与最长间隔、今日沟通上限、单轮扫描上限、连续运行时长与暂停时长。下方实时显示今日/本周沟通次数和本轮已筛选人数。
- **沟通话术** —— 多行文本，**一行一条模板**，运行时随机选一条发送。
- **滚动播报** —— 命中候选人的实时滚动列表。

**右栏**

- **运行概览** —— 当前状态与本次成功/跳过/失败/筛选计数。
- **运行结果与导出** —— 「打开日志目录」「清空日志窗口」。
- **实时日志** —— 按等级着色（蓝=信息、黄=警告、红=错误、青=成功）。

## 筛选规则说明

几条容易混淆的规则：

- **排除词优先级最高** —— 命中排除词的简历直接跳过，不再走后续判定。
- **学历按最低要求放行** —— 选「本科」则硕士、博士也会放行。
- **活跃度放宽一档** —— 选「今日活跃」时，会同时放行「刚刚活跃」和「今日活跃」。
- **简历关键词三档** —— 默认「包含任一词」；改成「必须全部词」则要求全部命中；「关闭包含词」则不按关键词过滤。
- **跳槽频率保守判定** —— 只有卡片上明确写出「X 年 X 家公司」这类信息时才会触发过滤，避免误伤没写工作经历的候选人。
- **目标公司词与屏蔽公司词** —— 目标公司词至少命中其一才放行；屏蔽公司词命中任一即排除。

## 输出文件

每次运行会在 `logs/<时间戳>/` 下生成一份独立记录：

| 文件 | 内容 |
| --- | --- |
| `matched_candidates.csv` | 命中并已打招呼的候选人 |
| `skipped_candidates.csv` | 被跳过的候选人及跳过原因 |
| `journal.jsonl` | 结构化事件流，便于事后排查 |
| `run.log` | 完整运行日志 |
| 异常截图 | 出错时的页面快照 |

另有 `logs/browser_console.log`，记录浏览器进程本身的输出，**浏览器打不开时先看这个文件**。

界面上的「打开日志目录」可直接跳转到该文件夹。

## 参数保存在哪

界面上的所有配置会写入用户主目录下的 `boss_recruiter_cfg.json`，关闭程序不会丢失，下次打开自动恢复。

## 常见问题

**提示「DrissionPage 导入失败」**

依赖没装。按 [快速开始](#快速开始) 第 2 步执行：

```bash
pip install -r requirements.txt
```

> 注意：如果你用的是打包版（带 `START_01_INSTALL.bat` 的那个），错误框会提示去运行那个 bat。**本仓库是单文件版，不包含该文件**，直接 `pip install -r requirements.txt` 即可。

**提示「未找到 Chrome 或 Edge 浏览器」**

程序会依次查注册表 `App Paths` 和常见安装路径。装了浏览器还报这个错，通常是把浏览器装到了非标准目录 —— 建议重装到默认路径。

**启动浏览器失败 / 提示「调试端口未就绪」**

多半是有残留的浏览器进程占着调试端口。按 `Ctrl+Shift+Esc` 打开任务管理器，**结束所有 Chrome 和 Edge 进程**后重新点「① 启动浏览器」。

**提示「浏览器接管失败」**

已经检测到 9333 端口有东西在跑，但不是程序自己拉起的浏览器。同样先清掉所有 Chrome/Edge 进程再重试。

**想换个账号登录 / 登录态失效了**

删掉 `browser_runtime/user_data` 整个目录，重新点「① 启动浏览器」扫码登录。

**一直跳过候选人 / 找不到元素**

页面结构改版的可能性最大，需要更新 `boss_recruiter.py` 里的元素定位逻辑。另外先确认浏览器窗口**保持在「推荐牛人」页面**且没有被最小化。

## 注意事项

- 请在**招聘者本人账号**下使用，并遵守 BOSS直聘 的平台规则。
- 程序默认间隔为「机器自适应」，每日沟通上限默认 **150**。建议不要调得过于激进 —— 频率异常是账号被限制的主要原因。
- 「连续运行时长」默认 **0（关闭）**，如需长时间挂机建议设为 30～60 分钟，让程序定期暂停。
- 运行期间**不要手动操作**程序打开的浏览器窗口，也不要关闭或最小化它，以免干扰页面元素定位。
